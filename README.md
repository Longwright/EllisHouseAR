# Ellis 9 House: phone AR viewer

**Viewer: https://longwright.github.io/EllisHouseAR/**

The house (building + MVHR + fan coils) at 1:1, one slice per floor, for phone AR
(WebXR, or Google Scene Viewer on Android) and an online 3D viewer on a wide screen.

- `index.html`: the page (Google model-viewer 3.5.0). Phone: one column. Width ≥ 900 px:
  3D viewer with the controls in a side panel. Toggles: free size in AR, Layers (show / hide
  each collection per floor, incl. the floor fill and the anchor), start at the stair landing.
- `m/HouseEM_AR_<BS|GF|F1|AT|ALL>.glb`: the models, one per floor + the whole house.

**Aligning on site:** the origin is the SW outer corner of the SW column GF-COL03 at that floor's
structural slab level (ALL: the ground-floor slab). It is marked by a red pole, a red bar along
the S face (pointing E) and a blue bar along the W face (pointing N).

**Updating:** the glbs are generated by `ar_export.py` in the private project repo
(`Hybrids/models3d/ar/`). Copy them into `m/`, commit and push; GitHub Pages republishes
in a minute or two.
